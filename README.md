Project Description

This project demonstrates the use of PL/SQL `GOTO` statements and user-defined functions in a payroll management scenario.

This assignment covers:

* Number classification using `GOTO`
* Employee salary review using `GOTO`
* Illegal `GOTO` and its correction
* Rewriting a program without `GOTO`
* Creating and using PL/SQL functions
* Using functions inside SQL `SELECT` statements
* Payroll validation using a PL/SQL function

How i did it

1. Open Oracle SQL Developer.
2. Connect to the Oracle database.
3. Run `00_setup/create_tables.sql` first.
4. Run the GOTO programs in the `01_goto` folder.
5. Run the functions in the `02_functions` folder.
6. Run the test programs in the `03_tests` folder.
7. Check the output in the Script Output window.
8. Save screenshots of the required outputs in the `screenshots` folder.

Business Scenario

The project uses a simple 'employee payroll system'. Employees belong to departments and have monthly salaries. PL/SQL programs and functions are used to classify salaries, calculate annual salaries and taxes, identify departments, calculate years of service, and validate payroll records.

Conclusion

This project demonstrates how Oracle PL/SQL can combine programming logic with database operations to solve practical payroll management problems.
